# 모바일 작업 목록

- 상태: 새 Expo 프로젝트·장소 추천·iOS Simulator 핵심 흐름 검증 완료, Android·실기기·스토어 검증 대기
- 갱신 기준일: 2026-08-20
- 기준 문서: [PRD](../1-prd.md)
- 전체 현황: [통합 작업 현황](../2-task_list.md)
- 범위: 활성 프로젝트 `../../mobile/`의 Expo 기반 Android·iOS 앱, NAVER 모바일 지도 SDK, 실제 기기 검증 및 스토어 배포

> 과거 모바일 구현의 범위와 Expo 재구성 기준은 [mobile-prd](../mobile-prd.md)에 정리한다.

> 모바일 앱에는 Cloud Run Base URL과 모바일 지도 SDK에 필요한 공개 설정만 포함한다. 서버용 API 키는 앱 번들에 포함하지 않는다.
