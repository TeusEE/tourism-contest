# 데이터 출처·이용 고지

앱은 다음 공식 API에서 확인한 데이터를 참고 정보로 표시한다.

- 지도·주소·자동차 경로: NAVER Maps
- 장소명·도로명 주소 후보: NAVER API HUB Local Search
- 행사·방문객·관광지 상대 집중률: 한국관광공사 TourAPI·데이터랩
- 여행지 단기예보: 기상청 공공데이터 API

장소 후보는 사용자가 선택한 뒤 분석 입력으로만 사용하며 서버에 저장하지 않는다. 행사 카드에는 제공자 이름, 신뢰도, 확인 시각과 공식 URL을 표시한다. 행사 이미지는 서버에 저장하거나 앱에 재배포하지 않는다. 방문객 값은 과거 참고값이며 미래 방문객 수 예측이 아니고, 혼잡 등급도 실제 교통 지연시간 예측이 아니다.

실제 배포 전에는 NAVER Maps 표시·로고·SDK/REST 이용 조건, 한국관광공사·기상청 출처 표시 조건, 연결하는 행사 공식 URL의 이용 조건을 서비스 운영자와 최종 확인한다. 이 문서는 구현 기준을 기록한 것이며 법률 자문을 대체하지 않는다.
