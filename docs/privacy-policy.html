1. 처리하는 개인정보의 항목과 목적

이 서비스는 회원가입이나 사용자 계정을 요구하지 않습니다. 앱은 사용자가 입력하거나 선택한 여행 계획을 분석 요청 동안 처리하고, 결과를 화면에 표시합니다.

항목 처리 목적 보유·이용 기간
출발지·여행지 검색어, 선택한 장소명·주소·좌표 주소 후보 표시, 좌표 변환, 자동차 경로와 목적지 주변 데이터 조회 분석 요청 및 앱 화면 상태가 유지되는 동안. 영구 저장하지 않음
여행일, 선택적 출발 예정 시각, 선택적 행사 유형 여행일과 겹치는 행사 후보 수, 방문객 참고값, 단기예보 조회 및 결과 표시 분석 요청 및 앱 화면 상태가 유지되는 동안. 영구 저장하지 않음
서비스 운영 로그: 요청 ID, HTTP 메서드·경로, 응답 상태, 처리 시간 장애 대응, 보안, 호출량·성능 모니터링 Google Cloud 운영·로그 보관 설정에 따른 기간

분석 서버의 애플리케이션 로그에는 요청 본문, 검색어, 좌표, API 키를 기록하지 않도록 구성되어 있습니다. 다만 Cloud Run·네트워크·보안 운영 과정에서 Google Cloud가 처리하는 접속·기술 정보는 해당 제공자의 정책과 로그 설정이 적용될 수 있습니다.

2. 수집하지 않는 정보

  • 앱은 현재 iOS 또는 Android의 위치 권한을 요청하지 않으며, 기기의 현재 위치를 수집하지 않습니다.
  • 연락처, 사진·미디어, 계정 비밀번호, 결제정보, 광고 식별자를 수집하지 않습니다.
  • 회원 프로필, 로그인 계정, 친구 목록, 사용자별 여행 기록을 만들거나 저장하지 않습니다.
  • 분석 결과는 현재 앱 메모리와 요청 처리 범위에서만 사용하며 영구 데이터베이스에 저장하지 않습니다.

정확한 지도·주소·공공데이터를 제공하기 위해 다음 외부 서비스에 필요한 범위의 검색어, 주소 또는 좌표가 전달될 수 있습니다. 각 제공자의 개인정보 처리방침과 이용약관도 함께 확인해 주세요.

외부 API 인증정보는 모바일 앱에 포함하지 않고 분석 서버의 Secret Manager 연동 환경에서 관리합니다. 지도 SDK에 사용되는 공개 Client ID는 서비스 식별을 위한 값이며 비밀키로 취급하지 않습니다.

4. 보유 및 파기

Travel Congestion은 사용자 계정이나 영구 여행 저장소를 운영하지 않습니다. 앱을 종료하거나 새 분석을 시작하면 앱 화면의 이전 입력과 결과는 더 이상 서비스 기능에 사용되지 않습니다. 분석 서버도 요청 본문과 결과를 영구 저장하지 않도록 구성되어 있습니다.

요청 ID와 처리시간 같은 최소 운영 로그, Cloud Run 접근 로그 및 보안 로그는 장애 대응과 법적·보안상 필요한 기간 동안 각 클라우드 로그 설정 및 제공자 정책에 따라 보관될 수 있으며, 보관기간 종료 후 파기 또는 익명화됩니다. 실제 배포 시 Google Cloud 로그 보관기간을 확인해 이 문서의 운영자 기록과 일치시켜야 합니다.

6. 개인정보의 안전성 확보조치

  • 외부 API 비밀키는 모바일 번들에 넣지 않고 서버 환경의 Secret Manager에서 관리합니다.
  • 서버 로그에는 요청 본문과 외부 API 인증정보를 남기지 않도록 필드를 제한합니다.
  • 분석 요청에는 본문 크기 제한, 입력 검증, 제공자별 타임아웃과 오류 분리를 적용합니다.
  • 서비스 운영자는 접근권한을 업무상 필요한 범위로 제한하고 배포·키 변경 이력을 관리합니다.

Travel Congestion은 아동을 대상으로 한 계정·프로필 서비스를 제공하지 않습니다. 보호자의 동의 없이 아동의 개인정보가 제공된 사실을 알게 된 경우 아래 문의처로 알려주시면 확인 후 필요한 조치를 하겠습니다.
