# 한국관광공사_빅데이터_지역별 방문자수

- 출처: [공공데이터포털 상세 페이지](https://www.data.go.kr/data/15101972/openapi.do)
- 수집 기준일: 2026-08-05
- 제공기관: 한국관광공사
- API 유형: REST
- 데이터 포맷: JSON+XML
- 키워드: 관광,빅데이터,데이터랩,이동통신,방문자

## 어떤 정보를 얻을 수 있나

㈜케이티(내국인)와 SK텔레콤(주)(외국인)의 이동통신 데이터를 기반으로 제공되는 광역 및 기초지자체별 방문자 수 정보입니다. ‘방문자’는 거주, 통근, 통학 등의 일상생활권을 벗어나 관광 등의 목적으로 한 장소에 일정시간 머문 사람으로, 정확한 방문목적을 알 수 없는 데이터 특성상의 한계로 ‘관광객’과 동일하게 정의되지 않습니다. 또한 방문자 수는 일자별 순방문자 수로서, 특정 방문자가 2박 3일간 한 지역을 방문했을 경우 3명으로 집계되며, 기초지자체와 광역지자체가 별도의 집계 기준을 가지고 있어 임의의 데이터 합산이 불가능합니다. 더 자세한 데이터 해석 유의사항은 한국관광 데이터랩(https://datalab.visitkorea.or.kr)의 데이터 설명을 참조 부탁드립니다.

## 사용 조건

- 비용: 무료
- 이용허락범위: 이용허락범위 제한 없음
- 심의유형: 개발단계 : 자동승인 / 운영단계 : 심의승인
- 신청 가능 트래픽: 개발계정 : 1,000 / 운영계정 : 활용사례 등록시 신청하면 트래픽 증가 가능
- 인증: 각 기능의 `serviceKey`에 공공데이터포털에서 발급받은 인증키를 전달해야 합니다.

## 호출 방법

Swagger 기준 버전은 `1.0.0`이며 Base URL은 다음과 같습니다.

```
https://apis.data.go.kr/B551011/DataLabService
```

각 기능의 HTTP 메서드와 경로를 Base URL 뒤에 붙여 호출합니다. 응답 형식은 보통 `_type=json`으로 JSON을 지정할 수 있으며, XML도 지원되는 경우가 있습니다. 아래 기능별 표에서 필수 파라미터를 채워 호출하세요.

## 상세 기능

### GET `/metcoRegnVisitrDDList` — 광역 지자체 지역방문자수 집계 데이터 정보 조회

광역 지자체 지역방문자수 집계 데이터 정보를 조회하는 기능입니다. 전체데이터관련 정보는 한국관광공사 TourAPI운영팀으로 문의해 주세요.

- 호출 주소: `https://apis.data.go.kr/B551011/DataLabService/metcoRegnVisitrDDList?MobileOS={MobileOS}&MobileApp={MobileApp}&serviceKey={SERVICE_KEY}&startYmd={startYmd}&endYmd={endYmd}`

#### 요청 파라미터

| 이름 | 필수 | 형식 | 위치 | 설명 |
|---|---:|---|---|---|
| `numOfRows` | 아니오 | number | (query) | 한페이지결과수 |
| `pageNo` | 아니오 | number | (query) | 페이지번호 |
| `MobileOS` | 예 | string | (query) | OS 구분 : IOS (아이폰), AND (안드로이드), WIN (윈도우폰), ETC(기타) |
| `MobileApp` | 예 | string | (query) | 서비스명(어플명) |
| `serviceKey` | 예 | string | (query) | 인증키(서비스키) |
| `startYmd` | 예 | string | (query) | 시작연월일(YYYYMMDD) |
| `endYmd` | 예 | string | (query) | 종료연월일(YYYYMMDD) |

#### 응답

| 코드 | 설명 |
|---:|---|
| 200 | 성공 |

성공 응답 예시(`200`):

```json
{
 "header": {
 "resultMsg": "string",
 "resultCode": "string"
 },
 "body": {
 "numOfRows": 0,
 "pageNo": 0,
 "totalCount": 0,
 "items": {
 "item": {
 "baseYmd": "string",
 "areaCode": "string",
 "areaNm": "string",
 "daywkDivCd": "string",
 "daywkDivNm": "string",
 "touDivCd": "string",
 "touDivNm": "string",
 "touNum": "string"
 }
 }
 }
}
```
