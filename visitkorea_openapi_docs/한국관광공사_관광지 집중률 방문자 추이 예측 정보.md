- 출처: [공공데이터포털 상세 페이지](https://www.data.go.kr/data/15128555/openapi.do)

- 데이터 포맷: JSON+XML

## 어떤 정보를 얻을 수 있나

㈜케이티의 이동통신 데이터를 기반으로 제공되는 관광지별 조회일 기준 향후 30일간의 관광지 방문자의 집중률 정보입니다. 2018년부터의 방문자 데이터를 기반으로 패턴을 분석하여 해당 관광지에 방문자가 얼마나 집중되는지를 예측한 값으로, 가장 붐비는 시기를 100으로 보았을 때 향후 30일간의 집중률을 상대 수치로 환산한 값입니다. ㈜케이티에 가입된 휴대전화 단말기를 소지한 사람의 이동 정보를 기반으로 평일/공휴일, 휴가시즌 등의 시기적 특성을 반영하여 머신러닝 기법으로 추정되었기 때문에 각종 환경변화에 따라 실제 방문자 수와 예측값 간에 차이가 있을 수 있습니다.

## 호출 방법

Swagger 기준 버전은 `1.0.0`이며 Base URL은 다음과 같습니다.

```
https://apis.data.go.kr/B551011/TatsCnctrRateService
```

각 기능의 HTTP 메서드와 경로를 Base URL 뒤에 붙여 호출합니다. 응답 형식은 보통 `_type=json`으로 JSON을 지정할 수 있으며, XML도 지원되는 경우가 있습니다. 아래 기능별 표에서 필수 파라미터를 채워 호출하세요.

## 상세 기능

### GET `/tatsCnctrRatedList` — 관광지 집중률 정보 목록조회

관광지별 향후 30일 관광객 집중률 정보를 목록을 조회하는 기능입니다.

- 호출 주소: `https://apis.data.go.kr/B551011/TatsCnctrRateService/tatsCnctrRatedList?serviceKey={SERVICE_KEY}&pageNo={pageNo}&numOfRows={numOfRows}&MobileOS={MobileOS}&MobileApp={MobileApp}&areaCd={areaCd}&signguCd={signguCd}&_type=json`

#### 요청 파라미터

| 이름 | 필수 | 형식 | 위치 | 설명 |
|---|---:|---|---|---|
| `serviceKey` | 예 | string | (query) | 공공데이터포털에서 받은 인증키 |
| `pageNo` | 예 | number | (query) | 페이지번호 |
| `numOfRows` | 예 | number | (query) | 한 페이지 결과 수 |
| `MobileOS` | 예 | string | (query) | OS 구분 : IOS (아이폰), AND (안드로이드), WEB(웹), ETC(기타) |
| `MobileApp` | 예 | string | (query) | 서비스명(어플명) |
| `areaCd` | 예 | string | (query) | 관광지 지역코드 ( 참고문서 매뉴얼 파일중 '관광지시군구코드정보' 파일 참고 ) |
| `signguCd` | 예 | string | (query) | 관광지 시군구코드 ( 참고문서 매뉴얼 파일중 '관광지시군구코드정보' 파일 참고 ) |
| `tAtsNm` | 아니오 | string | (query) | 관광지명 |
| `_type` | 아니오 | string | (query) | 응답메세지 형식 : REST방식의 URL호출 시 json값 추가(디폴트 응답메세지 형식은XML) |
