# 한국관광공사_무장애 여행 정보

- 출처: [공공데이터포털 상세 페이지](https://www.data.go.kr/data/15101897/openapi.do)
- 수집 기준일: 2026-08-05
- 제공기관: 한국관광공사
- API 유형: REST
- 데이터 포맷: JSON+XML
- 키워드: 무장애,장애인,무장애여행,한국관광,관광지,숙박,여행코스,음식점

## 어떤 정보를 얻을 수 있나

- 국내관광정보서비스 OpenAPI 신규 상세기능(법정동코드, 신분류코드) 안내 URL(https://api.visitkorea.or.kr/#/cmsNoticeDetail?no=207) - 장애인, 고령자, 영유아가족 등 '모든 관광객'이 이동의 불편 및 관광활동의 제약없이 이용할 수 있는 장애물 없는 정보이며,국내 최대 무장애 관광정보 포털 사이트 열린관광 모두의여행(access.visitkorea.or.kr) 홈페이지에서 제공하는 관광정보 중 저작권 등에 구애 없이 자유롭게 활용 가능한 정보만을 선별하여 OpenAPI를 통해서 최신정보를 제공하고 있습니다. - 개방 데이터는 지역코드정보, 서비스분류코드정보, 법정동코드정보, 분류체계코드정보, 지역기반관광정보, 위치기반관광정보, 키워드검색, 공통정보, 소개정보, 반복정보, 이미지정보, 무장애 정보, 무장애 여행정보 동기화 목록정보 13종 약 6만 건의 국내 관광에 대한 전반적인 정보를 국문로 제공합니다. - 모바일 앱 뿐만 아니라, 웹서비스, 태블릿, 홍보물, 잡지 등 다양한 매체에서 어플리케이션을 개발, 활용할 수 있으며 다양한 활용을 통해서 신규/융복합 관광서비스를 창출할 수 있습니다. ※ 제공되는 데이터중 사진 자료의 경우, 피사체에 대한 명예훼손 및 인격권 침해 등 일반 정서에 반하는 용도의 사용 및 기업 CI,BI로의 이용 금지하고 있습니다. (공공누리 1유형, 3유형 이미지 제공됨)

## 사용 조건

- 비용: 무료
- 이용허락범위: 이용허락범위 제한 없음
- 심의유형: 개발단계 : 자동승인 / 운영단계 : 심의승인
- 신청 가능 트래픽: 개발계정 : 1,000 / 운영계정 : 활용사례 등록시 신청하면 트래픽 증가 가능
- 인증: 각 기능의 `serviceKey`에 공공데이터포털에서 발급받은 인증키를 전달해야 합니다.

## 호출 방법

Swagger 기준 버전은 `1.0.0`이며 Base URL은 다음과 같습니다.

```
https://apis.data.go.kr/B551011/KorWithService2
```

각 기능의 HTTP 메서드와 경로를 Base URL 뒤에 붙여 호출합니다. 응답 형식은 보통 `_type=json`으로 JSON을 지정할 수 있으며, XML도 지원되는 경우가 있습니다. 아래 기능별 표에서 필수 파라미터를 채워 호출하세요.
