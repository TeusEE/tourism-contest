# 한국관광공사_관광지 오디오 가이드정보

- 출처: [공공데이터포털 상세 페이지](https://www.data.go.kr/data/15101971/openapi.do)
- 수집 기준일: 2026-08-05
- 제공기관: 한국관광공사
- API 유형: REST
- 데이터 포맷: JSON+XML
- 키워드: 관광지,오디,관광해설,음성가이드,여행,역사,오디오가이드,팟캐스트

## 어떤 정보를 얻을 수 있나

한국관광공사에서 제공하는 디지털 오디오 관광 해설 서비스인 오디(Odii)에 있는 콘텐츠의 음성, 대본, 사진 정보를 OpenAPI를 통해 무료로 제공합니다. 개방 데이터튼 관광지 기본 정보, 관광지 및 이야기 위치 기반 정보, 관광지 및 이야기 키워드 검색 목록, 정보 동기화 목록 등입니다. 오디(Odii)는 모바일 앱 뿐만 아니라 웹(www.odii.kr)을 통해서도 이용할 수 있는 오디오 가이드 서비스이며, 통합검색 및 위치 기반으로 편리하게 전국 주요 관광지의 이야기를 검색할 수 있습니다. 한국어, 영어, 중국어, 일본어로 다양한 관광지에 담긴 역사와 문화 이야기를 제공하고 있습니다. 제공되는 데이터를 이용해 오디오 가이드 관련 앱, 웹 서비스 개발 등에 활용할 수 있습니다.

## 사용 조건

- 비용: 무료
- 이용허락범위: 이용허락범위 제한 없음
- 심의유형: 개발단계 : 자동승인 / 운영단계 : 심의승인
- 신청 가능 트래픽: 개발계정 : 1,000 / 운영계정 : 활용사례 등록시 신청하면 트래픽 증가 가능
- 인증: 각 기능의 `serviceKey`에 공공데이터포털에서 발급받은 인증키를 전달해야 합니다.

## 호출 방법

Swagger 기준 버전은 `1.0.0`이며 Base URL은 다음과 같습니다.

```
https://apis.data.go.kr/B551011/Odii
```

각 기능의 HTTP 메서드와 경로를 Base URL 뒤에 붙여 호출합니다. 응답 형식은 보통 `_type=json`으로 JSON을 지정할 수 있으며, XML도 지원되는 경우가 있습니다. 아래 기능별 표에서 필수 파라미터를 채워 호출하세요.
