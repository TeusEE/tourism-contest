# 한국관광공사_웰니스관광정보

- 출처: [공공데이터포털 상세 페이지](https://www.data.go.kr/data/15144030/openapi.do)
- 수집 기준일: 2026-08-05
- 제공기관: 한국관광공사
- API 유형: REST
- 데이터 포맷: JSON+XML
- 키워드: 웰니스 관광,힐링,명상,뷰티,스파,자연치유,푸드,스테이

## 어떤 정보를 얻을 수 있나

한국관광공사가 보유하고 있는 다양한 웰니스 관광 정보를 실시간으로 제공 받을 수 있으며, 국내 최대 관광정보 포털사이트(www.visitkorea.or.kr) 홈페이지에서 제공하는 웰니스 관광정보 중 저작권 등에 구애 없이 자유롭게 활용 가능한 정보만을 선별하여 OpenAPI를 통해서 최신 정보를 제공하고 있습니다. - 개방 데이터는 법정동 코드 정보, 지역기반 관광정보, 위치기반 관광정보, 키워드 검색, 웰니스 관광 동기화 정보, 공통정보, 소개정보, 반복정보, 이미지정보 9종으로 전반적인 국내 웰니스 관광 정보를 여러가지 언어로 제공합니다. - 모바일 앱 뿐만 아니라, 웹 서비스, 태블릿, 홍보물, 잡지 등 다양한 매체에서 어플리케이션을 개발, 활용할 수 있으며, 다양한 활동을 통해서 신규/융복합 관광 서비스를 창출할 수 있습니다

## 사용 조건

- 비용: 무료
- 이용허락범위: 이용허락범위 제한 없음
- 심의유형: 개발단계 : 자동승인 / 운영단계 : 심의승인
- 신청 가능 트래픽: 개발계정 : 1,000 / 운영계정 : 활용사례 등록시 신청하면 트래픽 증가 가능
- 인증: 각 기능의 `serviceKey`에 공공데이터포털에서 발급받은 인증키를 전달해야 합니다.

Swagger 기준 버전은 `1.0.0`이며 Base URL은 다음과 같습니다.


각 기능의 HTTP 메서드와 경로를 Base URL 뒤에 붙여 호출합니다. 응답 형식은 보통 `_type=json`으로 JSON을 지정할 수 있으며, XML도 지원되는 경우가 있습니다. 아래 기능별 표에서 필수 파라미터를 채워 호출하세요.

## 상세 기능

### GET `/ldongCode` — 법정동 코드 조회

법정동 코드 목록을 지역, 시군구, 읍면동 코드 목록을 조회하는 기능입니다. 지역기반 관광정보 및 키워드 검색 등을 통해 지역 별로 목록을 보여줄 경우, 법정동 코드를 이용하여 법정동명을 매칭하기 위한 기능입니다.

- 호출 주소: `https://apis.data.go.kr/B551011/WellnessTursmService/ldongCode?serviceKey={SERVICE_KEY}&MobileOS={MobileOS}&MobileApp={MobileApp}&langDivCd={langDivCd}&_type=json`

#### 요청 파라미터

| 이름 | 필수 | 형식 | 위치 | 설명 |
|---|---:|---|---|---|
| `serviceKey` | 예 | string | (query) | 공공데이터포털에서 받은 인증키 |
| `numOfRows` | 아니오 | number | (query) | 한 페이지 결과 수 |
| `pageNo` | 아니오 | number | (query) | 현재 페이지 번호 |
| `MobileOS` | 예 | string | (query) | OS 구분 : IOS (아이폰), AND (안드로이드), WIN (윈도우폰), ETC |
| `MobileApp` | 예 | string | (query) | 서비스명(어플명) |
| `langDivCd` | 예 | string | (query) | 언어 구분 코드 (KOR: 한국어, ENG: 영어, JPN: 일어, CHS: 중국어(간체), CHT: 중국어(번체), GER: 독일어, FRE: 프랑스어, SPN: 스페인어, RUS: 러시아어) |
| `lDongRegnCd` | 아니오 | string | (query) | 법정동 시도코드 (lDongRegnCd 해당되는 법정동 시군구코드 조회 , 입력이 없을 시 전체 시도목록 호출) |
| `lDongListYn` | 아니오 | string | (query) | 법정동 목록조회 여부 (N: 코드조회 , Y: 전체목록조회) |
| `_type` | 아니오 | string | (query) | 응답메세지 형식: REST 방식의 URL 호출 시 json값 추가 (디폴트 응답메세지 형식 XML) |
