# 한국관광공사_지역별 관광 자원 수요

- 출처: [공공데이터포털 상세 페이지](https://www.data.go.kr/data/15152138/openapi.do)
- 수집 기준일: 2026-08-05
- 제공기관: 한국관광공사
- API 유형: REST
- 데이터 포맷: JSON+XML
- 키워드: 데이터랩,관광 수요 지수,관광 경쟁력,지자체,관광 자원 수요,관광 서비스 수요,문화 자원 수요,검색량

## 어떤 정보를 얻을 수 있나

본 API는 한국관광공사 한국관광데이터랩의 관광수요지수(https://datalab.visitkorea.or.kr/datalab/portal/loc/getTourActivateForm.do)에서 제공하는 관광 자원 수요 정보를 제공합니다. 관광 자원 수요는 관광 빅데이터(신용카드, 이동 통신, 내비게이션)를 활용하여 해당 지역의 관광 산업 수요 활성화 정도를 평가하는 지수인 관광 수요 지수를 구성하는 지표 중 하나입니다. 관광 서비스 수요(유형별 SNS 언급량, 업종별 관광 소비액, 내비게이션 유형별 목적지 검색량), 문화 자원 수요(내비게이션 유형별 목적지 검색량) 등 세부 지표로 구성되어 있으며 각 세부 지표별 하위 지표의 평균값을 보여줍니다. - 개방데이터는 지역별 관광 서비스 수요 정보, 지역별 문화 자원 수요 정보 조회 기능 총 2종으로 구성되어 제공합니다. - 개방데이터는 홍보물, 잡지 등 다양한 매체에서 활용할 수 있으며, 모바일 앱, 웹 서비스 등 신규/융복합 관광 서비스 개발에도 활용할 수 있습니다.

## 사용 조건

- 비용: 무료
- 이용허락범위: 이용허락범위 제한 없음
- 심의유형: 개발단계 : 자동승인 / 운영단계 : 심의승인
- 신청 가능 트래픽: 개발계정 : 1,000 / 운영계정 : 활용사례 등록시 신청하면 트래픽 증가 가능
- 인증: 각 기능의 `serviceKey`에 공공데이터포털에서 발급받은 인증키를 전달해야 합니다.

## 호출 방법

Swagger 기준 버전은 `1.0.0`이며 Base URL은 다음과 같습니다.

```
https://apis.data.go.kr/B551011/AreaTarResDemService
```

각 기능의 HTTP 메서드와 경로를 Base URL 뒤에 붙여 호출합니다. 응답 형식은 보통 `_type=json`으로 JSON을 지정할 수 있으며, XML도 지원되는 경우가 있습니다. 아래 기능별 표에서 필수 파라미터를 채워 호출하세요.

## 상세 기능

### GET `/areaTarSvcDemList` — 지역별 관광 서비스 수요 정보 목록 조회

지역별 관광 서비스 수요 정보 목록을 조회하는 기능입니다. * 관광 서비스 수요 (Demand for Tourism Services) : SNS 언급량, 소비액, 내비게이션 검색량 세부 지표로 구성 1) SNS 언급량: 각 지자체별 관광 관련 언급량 중 레포츠/휴식 힐링/미식/체험 여행 유형별 키워드 언급 수 2) 소비액: 각 지자체별 쇼핑업/식음료/숙박업/운송업/여가 서비스업 업종별 소비액 3) 내비게이션 검색량: 각 지자체별 내비게이션 목적지 검색량 중 숙박/음식/쇼핑 유형별 목적지 검색량

- 호출 주소: `https://apis.data.go.kr/B551011/AreaTarResDemService/areaTarSvcDemList?serviceKey={SERVICE_KEY}&MobileOS={MobileOS}&MobileApp={MobileApp}&baseYm={baseYm}&areaCd={areaCd}&_type=json`

#### 요청 파라미터

| 이름 | 필수 | 형식 | 위치 | 설명 |
|---|---:|---|---|---|
| `serviceKey` | 예 | string | (query) | 공공데이터포털에서 받은 인증키 (서비스키) |
| `numOfRows` | 아니오 | number | (query) | 한 페이지 결과 수 |
| `pageNo` | 아니오 | number | (query) | 현재 페이지 번호 |
| `MobileOS` | 예 | string | (query) | OS 구분 : IOS (아이폰), AND (안드로이드), WEB (웹사이트), ETC |
| `MobileApp` | 예 | string | (query) | 서비스명(어플명) |
| `baseYm` | 예 | string | (query) | 조회 기준 연월 (형식 : YYYYMM) |
| `areaCd` | 예 | string | (query) | 지역 코드 (지역/시군구 코드 파일 참고) |
| `signguCd` | 아니오 | string | (query) | 시군구 코드 (지역/시군구 코드 파일 참고) |
| `tarSvcDemIxCd` | 아니오 | string | (query) | 관광 서비스 수요 지표 코드 (11 : 전체, 1101 : 레포츠 SNS 언급량, 1102 : 휴식 힐링 SNS 언급량, 1103 : 미식 SNS 언급량, 1104 : 체험 SNS 언급량, 1105 : 쇼핑업 소비액, 1106 : 식음료 소비액, 1107 : 숙박업 소비액, 1108 : 여가 서비스업 소비액, 1109 : 운송업 소비액, 1110 : 내비게이션 숙박 검색량, 1111 : 내비게이션 음식 검색량, 1112 : 내비게이션 쇼핑 검색량) |
| `_type` | 아니오 | string | (query) | 응답 메세지 형식 : REST 방식의 URL 호출 시 json값 추가(디폴트 응답 메세지 형식 XML) |
