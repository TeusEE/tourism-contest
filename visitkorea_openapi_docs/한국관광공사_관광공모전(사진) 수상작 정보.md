# 한국관광공사_관광공모전(사진) 수상작 정보

- 출처: [공공데이터포털 상세 페이지](https://www.data.go.kr/data/15145706/openapi.do)
- 수집 기준일: 2026-08-05
- 제공기관: 한국관광공사
- API 유형: REST
- 데이터 포맷: JSON+XML
- 키워드: 관광공모전,사진공모전,관광사진공모전,포토코리아,한국관광,국내관광지,문화유산,풍경

## 어떤 정보를 얻을 수 있나

본 API는 한국관광공사 포토코리아(phoko.visitkorea.or.kr)에서 제공하는 관광공모전 사진 부문 수상작에 대한 제목, 촬영일, 촬영지, 키워드, 이미지 정보 등을 제공합니다. - 개방데이터는 법정동코드 정보, 관광공모전(사진) 수상작 정보, 관광공모전(사진) 수상작 동기화 정보 총 3종으로 구성되어 있으며, 관광공모전 사진 부문 수상작에 대한 정보를 제공합니다. - 개방데이터는 홍보물, 잡지 등 다양한 매체에서 활용할 수 있으며, 모바일 앱, 웹 서비스 등 신규/융복합 관광서비스 개발에도 활용할 수 있습니다.

## 사용 조건

- 비용: 무료
- 이용허락범위: 이용허락범위 제한 없음
- 심의유형: 개발단계 : 자동승인 / 운영단계 : 심의승인
- 신청 가능 트래픽: 개발계정 : 1,000 / 운영계정 : 활용사례 등록시 신청하면 트래픽 증가 가능
- 인증: 각 기능의 `serviceKey`에 공공데이터포털에서 발급받은 인증키를 전달해야 합니다.

## 호출 방법

Swagger 기준 버전은 `1.0.0`이며 Base URL은 다음과 같습니다.

```
https://apis.data.go.kr/B551011/PhokoAwrdService
```

각 기능의 HTTP 메서드와 경로를 Base URL 뒤에 붙여 호출합니다. 응답 형식은 보통 `_type=json`으로 JSON을 지정할 수 있으며, XML도 지원되는 경우가 있습니다. 아래 기능별 표에서 필수 파라미터를 채워 호출하세요.

## 상세 기능

### GET `/ldongCode` — 법정동 코드 조회

법정동 코드정보를 조회하는 기능입니다. 지역기반 수상작 정보를 지역 별로 목록을 보여줄 경우, 법정동 코드를 이용하여 법정동명을 매칭하기 위한 기능입니다.

- 호출 주소: `https://apis.data.go.kr/B551011/PhokoAwrdService/ldongCode?serviceKey={SERVICE_KEY}&MobileOS={MobileOS}&MobileApp={MobileApp}&_type=json`

#### 요청 파라미터

| 이름 | 필수 | 형식 | 위치 | 설명 |
|---|---:|---|---|---|
| `serviceKey` | 예 | string | (query) | 공공데이터포털에서 받은 인증키 |
| `numOfRows` | 아니오 | number | (query) | 한 페이지 결과 수 |
| `pageNo` | 아니오 | number | (query) | 페이지 번호 |
| `MobileOS` | 예 | string | (query) | OS 구분 : IOS (아이폰), AND (안드로이드), WIN (윈도우폰), ETC |
| `MobileApp` | 예 | string | (query) | 서비스명(어플명) |
| `_type` | 아니오 | string | (query) | 응답메세지 형식: REST 방식의 URL 호출 시 json값 추가 (디폴트 응답메세지 형식 XML) |

#### 응답

| 코드 | 설명 |
|---:|---|
| 10 | 잘못된 요청 파라미터 에러 (INVALID_REQUEST_PARAMETER_ERROR) |
| 11 | 필수 요청 파라미터가 없음(NO_MANDATORY_REQUEST_PARAMETERS_ERROR) |
| 21 | 일시적으로 사용할 수 없는 서비스키(TEMPORARILY_DISABLE_THE_SERVICEKEY_ERROR) |
| 33 | 서명되지 않은 호출(UNSIGNED_CALL_ERROR) |
| 200 | 성공 |
| 02 | 데이터베이스 에러(DB_ERROR) |
| 03 | 데이터 없음 에러(NODATA_ERROR) |
| 05 | 서비스 연결 실패 에러(SERVICETIMEOUT_ERROR) |
| 00 | 정상(NORMAL_CODE) |

성공 응답 예시(`200`):

```json
{
 "header": {
 "resultMsg": "string",
 "resultCode": "string"
 },
 "body": {
 "items": {
 "item": {
 "rnum": "string",
 "lDongRegnCd": "string",
 "lDongRegnNm": "string"
 }
 },
 "numOfRows": 0,
 "pageNo": 0,
 "totalCount": 0
 }
}
```
### GET `/phokoAwrdList` — 관광공모전(사진) 수상작 정보 목록 조회

키워드 또는 법정동 코드로 검색하여 관광공모전 사진 부문 수상작 목록을 조회하는 기능입니다. 정렬 구분 파라미터를 통해 제목순, 수정일순(최신순), 생성일순 정렬검색을 제공합니다.

- 호출 주소: `https://apis.data.go.kr/B551011/PhokoAwrdService/phokoAwrdList?serviceKey={SERVICE_KEY}&MobileOS={MobileOS}&MobileApp={MobileApp}&_type=json`

#### 요청 파라미터

| 이름 | 필수 | 형식 | 위치 | 설명 |
|---|---:|---|---|---|
| `serviceKey` | 예 | string | (query) | 공공데이터포털에서 받은 인증키(서비스키) |
| `numOfRows` | 아니오 | number | (query) | 한 페이지 결과 수 |
| `pageNo` | 아니오 | number | (query) | 현재 페이지 번호 |
| `MobileOS` | 예 | string | (query) | OS 구분 : IOS (아이폰), AND (안드로이드), WIN (윈도우), ETC |
| `MobileApp` | 예 | string | (query) | 서비스명(어플명) |
| `arrange` | 아니오 | string | (query) | 정렬 구분 (A=제목순, C=수정일순, D=생성일순), 대표 이미지 포함 정렬 (O=제목순, Q=수정일순, R=생성일순) |
| `mdfcnDt` | 아니오 | string | (query) | 콘텐츠 수정일(형식: YYYYMMDD) |
