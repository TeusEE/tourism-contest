- 출처: [공공데이터포털 상세 페이지](https://www.data.go.kr/data/15125070/openapi.do)
- 수집 기준일: 2026-08-05
- 제공기관: 한국관광공사
- API 유형: REST
- 데이터 포맷: JSON+XML
- 키워드: 일자리,관광,취업,인재,직무 교육,취업 박람회,취업 준비,입사 지원

## 어떤 정보를 얻을 수 있나

관광전문인력포털은 관광 산업 내 인력 수급 불균형 해소 및 고용 촉진을 위해 관광 기업의 채용 정보를 수집 및 제공하고 있습니다. 본 데이터는 관광 기업이 직접 등록한 채용공고 또는 유관기관 연계를 통해 수집된 것으로 채용 분야, 직무, 지역, 기업 정보, 마감일 등으로 구성되어 있습니다. 해당 데이터는 민간 및 공공기관이 관광 분야 채용 동향을 파악하거나 관련 서비스를 설계 및 운영하는데 기초 자료로 활용될 수 있습니다. 특히 취업 지원 기관, 교육기관, 지자체 등에서 관광 일자리 정보 접근성을 높이기 위한 참고자료로 활용될 수 있으며 구직자에게는 분야별 일자리 흐름을 확인하고 맞춤형 구직 전략을 세우는 데 도움이 될 수 있습니다.

- 비용: 무료
- 이용허락범위: 이용허락범위 제한 없음

- 신청 가능 트래픽: 개발계정 : 1,000 / 운영계정 : 활용사례 등록시 신청하면 트래픽 증가 가능
- 인증: 각 기능의 `serviceKey`에 공공데이터포털에서 발급받은 인증키를 전달해야 합니다.

### GET `/code` — 코드 조회

지역, 직업명세, 공통코드 목록을 조회하는 기능입니다. 코드를 조회 해 채용정보 목록의 검색조건 및 결과값 매칭에 사용됩니다.

- 호출 주소: `https://apis.data.go.kr/B551011/tursmService/code?MobileOS={MobileOS}&MobileApp={MobileApp}&_type={_type}&codeType={codeType}&serviceKey={SERVICE_KEY}&_type=json`

#### 요청 파라미터

| 이름 | 필수 | 형식 | 위치 | 설명 |
|---|---:|---|---|---|
| `numOfRows` | 아니오 | number | (query) | 한페이지결과수 |
| `pageNo` | 아니오 | number | (query) | 페이지번호 |
| `MobileOS` | 예 | string | (query) | OS 구분 : IOS (아이폰), AND (안드로이드), WIN (윈도우폰), ETC(기타) |
| `MobileApp` | 예 | string | (query) | 서비스명(어플명) |
| `_type` | 예 | string | (query) | 응답메세지 형식 : REST방식의 URL호출 시 json값 추가(디폴트 응답메세지 형식은XML) |
| `codeType` | 예 | string | (query) | 코드 검색 조건 (AREA : 지역, JOB : 직업, COMM: 공통) |
| `code` | 아니오 | string | (query) | 코드에 해당하는 하위코드 조회 (직업코드는 상,중,하위 코드 존재, 그 외 중,하위 코드 존재) |
