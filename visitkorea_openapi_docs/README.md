# 한국관광 데이터 API 라우터

관광 서비스를 만들 때 “어떤 데이터를 어디서 받아야 하지?”를 먼저 해결하는 페이지입니다. 아래에서 만들고 싶은 기능을 고른 다음, 연결된 API 문서를 열어 필요한 엔드포인트와 파라미터를 확인하세요.

전체 API 목록의 원본은 [한국관광콘텐츠랩 OpenAPI 목록](https://api.visitkorea.or.kr/#/useUtilExercises)입니다.

### 일반 관광정보 기능 라우팅

언어별 관광정보 문서에서 다음 기능을 조합하면 대부분의 관광 앱을 만들 수 있습니다.

| 필요한 데이터 | 확인할 기능 |
|---|---|
| 지역 코드 | `areaCode2`, `ldongCode2` |
| 카테고리·분류 코드 | `categoryCode2`, `lclsSystmCode2` |
| 지역별 관광지 목록 | `areaBasedList2` |
| 좌표 주변 관광지 목록 | `locationBasedList2` |
| 키워드 관광지 검색 | `searchKeyword2` |
| 축제·행사 목록 | `searchFestival2` |
| 숙박 목록 | `searchStay2` |
| 관광지 공통 정보 | `detailCommon2` |
| 관광지 소개 정보 | `detailIntro2` |
| 코스·메뉴 등 반복 정보 | `detailInfo2` |
| 이미지 정보 | `detailImage2` |
| 변경분 수집·동기화 | `areaBasedSyncList2` |

국문 서비스에는 반려동물 동반 상세 기능인 `detailPetTour2`도 포함되어 있습니다. 무장애·반려동물 데이터가 핵심인 서비스라면 전용 문서를 우선 사용하세요.

## 자주 쓰는 API 조합

| 서비스 화면 | 추천 API 조합 |
|---|---|
| 관광지 목록 → 상세 화면 | `areaBasedList2` 또는 `searchKeyword2` → `detailCommon2` + `detailIntro2` + `detailImage2` |
| 내 주변 관광지 지도 | `locationBasedList2` → `detailCommon2` |
| 지역 축제 캘린더 | `searchFestival2` → `detailCommon2` |
| 반려동물 여행 지도 | 반려동물 서비스의 `locationBasedList2` → `detailPetTour2` + `detailImage2` |
| 무장애 여행 코스 | 무장애 서비스의 `areaBasedList2` → `detailWithTour2` + `detailImage2` |
| 관광 분석 대시보드 | 방문자수 API + 관광 수요 강도/자원 수요/다양성 API |
| 추천 관광지 화면 | `관광지별 연관 관광지 정보` → 일반 관광정보 API의 상세 기능 |

## 바이브코딩에 바로 넣는 프롬프트

아래 템플릿에서 대괄호 부분만 바꿔 AI 코딩 도구에 전달하세요. API 문서 링크를 함께 주면 AI가 Base URL, 필수 파라미터, 응답 구조를 문서 기준으로 구현할 수 있습니다.

```text
한국관광공사 OpenAPI로 [만들고 싶은 서비스]를 만들어줘.

참조할 API 문서:
[README에서 선택한 API 문서 링크]

사용할 기능:
- [예: GET /locationBasedList2]
- [예: GET /detailCommon2]
- [예: GET /detailImage2]

요구사항:
1. 프론트엔드에 serviceKey를 노출하지 말고 서버 API 라우트에서만 호출해줘.
2. serviceKey는 환경변수 VISITKOREA_SERVICE_KEY에서 읽어줘.
3. API 요청 파라미터는 URLSearchParams로 조립하고, 사용자가 입력한 값은 URL 인코딩해줘.
4. 문서에 표시된 필수 파라미터를 모두 검증하고 누락되면 친절한 오류를 반환해줘.
5. 응답의 성공 코드와 오류 코드를 처리하고, body.items.item이 배열이 아닐 때도 화면에서 처리할 수 있게 정규화해줘.
6. 로딩·빈 결과·API 오류 상태를 UI에 표시해줘.
7. [사용할 프레임워크: Next.js / React / Python FastAPI 등] 기준으로 실행 가능한 코드와 환경변수 예시를 만들어줘.
```

## 구현할 때 지켜야 할 공통 규칙

1. 공공데이터포털에서 API 활용신청을 하고 `serviceKey`를 발급받습니다.
2. 키는 `.env`에 저장하고 브라우저 번들·Git 저장소·로그에 넣지 않습니다.
3. 각 API 문서의 호출 주소에서 `{SERVICE_KEY}`와 나머지 자리표시자를 실제 값으로 바꿉니다.
4. JSON 응답이 필요하면 문서에 있는 `_type=json`을 사용합니다. 문서별 응답 예시를 기준으로 필드명을 확인하세요.
5. 목록 API는 `numOfRows`, `pageNo`를 사용해 페이지네이션합니다.
6. 일부 응답은 항목이 1개일 때 객체, 여러 개일 때 배열로 올 수 있으므로 앱 내부에서 배열로 정규화하는 것이 안전합니다.
7. 운영 전에는 개발계정 트래픽 한도, 오류 코드, 이미지 이용 조건을 각 API 문서에서 다시 확인합니다.
