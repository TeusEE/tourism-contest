# 한국관광공사_지역별 관광 다양성

- 출처: [공공데이터포털 상세 페이지](https://www.data.go.kr/data/15151365/openapi.do)
- 수집 기준일: 2026-08-05
- 제공기관: 한국관광공사
- API 유형: REST
- 데이터 포맷: JSON+XML
- 키워드: 데이터랩,관광 수요 지수,관광 경쟁력,지자체,관광 다양성,관광객 다양성,관광 소비 다양성,국제적 다양성

## 어떤 정보를 얻을 수 있나

본 API는 한국관광공사 한국관광데이터랩의 관광수요지수(https://datalab.visitkorea.or.kr/datalab/portal/loc/getTourActivateForm.do)에서 제공하는 관광 다양성 정보를 제공합니다. 관광 다양성은 관광 빅데이터(신용카드, 이동 통신, 내비게이션)를 활용하여 해당 지역의 관광 산업 수요 활성화 정도를 평가하는 지수인 관광 수요 지수를 구성하는 지표 중 하나입니다. 관광객 다양성(연령별 방문객 수), 관광소비 다양성(연령별 소비액), 국제적 다양성(외국인 소비액, 국적별 방문자 수, 방문객 국적 다양성) 등 세부 지표로 구성되어 있으며 각 세부 지표별 하위 지표의 평균값을 보여줍니다. - 개방데이터는 지역별 관광객 다양성 정보, 지역별 관광 소비 다양성 정보, 지역별 국제적 다양성 정보 조회 기능 총 3종으로 구성되어 제공합니다. - 개방데이터는 홍보물, 잡지 등 다양한 매체에서 활용할 수 있으며, 모바일 앱, 웹 서비스 등 신규/융복합 관광 서비스 개발에도 활용할 수 있습니다.

## 사용 조건

- 비용: 무료
- 이용허락범위: 이용허락범위 제한 없음
- 심의유형: 개발단계 : 자동승인 / 운영단계 : 심의승인
- 신청 가능 트래픽: 개발계정 : 1,000 / 운영계정 : 활용사례 등록시 신청하면 트래픽 증가 가능
- 인증: 각 기능의 `serviceKey`에 공공데이터포털에서 발급받은 인증키를 전달해야 합니다.

## 호출 방법

Swagger 기준 버전은 `1.0.0`이며 Base URL은 다음과 같습니다.

```
https://apis.data.go.kr/B551011/AreaTarDivService
```

각 기능의 HTTP 메서드와 경로를 Base URL 뒤에 붙여 호출합니다. 응답 형식은 보통 `_type=json`으로 JSON을 지정할 수 있으며, XML도 지원되는 경우가 있습니다. 아래 기능별 표에서 필수 파라미터를 채워 호출하세요.

## 상세 기능

### GET `/areaTouDivList` — 지역별 관광객 다양성 정보 목록 조회

지역별 관광객 다양성 정보 목록을 조회하는 기능입니다. * 관광객 다양성 (Tourist Diversity): 연령별 방문객 수 세부 지표로 구성 1) 연령별 방문객 수: 각 지자체를 방문한 이동 인구 중 연령대별(10대 ~ 70대) 방문객수

- 호출 주소: `https://apis.data.go.kr/B551011/AreaTarDivService/areaTouDivList?serviceKey={SERVICE_KEY}&MobileOS={MobileOS}&MobileApp={MobileApp}&baseYm={baseYm}&areaCd={areaCd}&_type=json`

#### 요청 파라미터

| 이름 | 필수 | 형식 | 위치 | 설명 |
|---|---:|---|---|---|
| `serviceKey` | 예 | string | (query) | 공공데이터포털에서 받은 인증키 (서비스키) |
| `numOfRows` | 아니오 | number | (query) | 한 페이지 결과 수 |
| `pageNo` | 아니오 | number | (query) | 현재 페이지 번호 |
| `MobileOS` | 예 | string | (query) | OS 구분 : IOS (아이폰), AND (안드로이드), WEB (웹사이트), ETC |
| `MobileApp` | 예 | string | (query) | 서비스명(어플명) |
| `baseYm` | 예 | string | (query) | 조회 기준 연월 (형식 : YYYYMM) |
| `areaCd` | 예 | string | (query) | 지역 코드 (지역/시군구 코드 파일 참고) |
| `signguCd` | 아니오 | string | (query) | 시군구 코드 (지역/시군구 코드 파일 참고) |
| `touDivIxCd` | 아니오 | string | (query) | 관광객 다양성 지표 코드 (31 : 전체, 3101 : 10대 방문객수, 3102 : 20대 방문객수, 3103 : 30대 방문객수, 3104 : 40대 방문객수, 3105 : 50대 방문객수, 3106 : 60대 방문객수, 3107 : 70대 방문객수) |
| `_type` | 아니오 | string | (query) | 응답 메세지 형식 : REST 방식의 URL 호출 시 json값 추가(디폴트 응답 메세지 형식 XML) |

#### 응답

| 코드 | 설명 |
|---:|---|
| 10 | 잘못된 요청 파라미터 에러 (INVALID_REQUEST_PARAMETER_ERROR) |
| 11 | 필수 요청 파라미터가 없음 (NO_MANDATORY_REQUEST_PARAMETERS_ERROR) |
| 21 | 일시적으로 사용할 수 없는 서비스키 (TEMPORARILY_DISABLE_THE_SERVICEKEY_ERROR) |
| 33 | 서명되지 않은 호출 (UNSIGNED_CALL_ERROR) |
| 200 | 성공 |
| 00 | 정상(NORMAL_CODE) |
| 02 | 데이터베이스 에러 (DB_ERROR) |
| 03 | 데이터 없음 에러 (NODATA_ERROR) |
| 05 | 서비스 연결 실패 에러 (SERVICETIMEOUT_ERROR) |

성공 응답 예시(`200`):

```json
{
 "header": {
 "resultCode": "string",
 "resultMsg": "string"
 },
 "body": {
 "items": {
 "item": {
 "baseYm": "string",
 "areaCd": "string",
 "areaNm": "string",
 "signguCd": "string",
 "signguNm": "string",
 "touDivIxCd": "string",
 "touDivIxNm": "string",
 "touDivIxVal": "string"
 }
 },
 "numOfRows": 0,
 "pageNo": 0,
 "totalCount": 0
 }
}
```
