# 한국관광공사_두루누비 정보 서비스

- 출처: [공공데이터포털 상세 페이지](https://www.data.go.kr/data/15101974/openapi.do)
- 수집 기준일: 2026-08-05
- 제공기관: 한국관광공사
- API 유형: REST
- 데이터 포맷: JSON+XML
- 키워드: 걷기,걷기 여행,걷기 여행길,코리아둘레길,두루누비,둘레길,레저 여행,트레킹

## 어떤 정보를 얻을 수 있나

본 API는 한국관광공사에서 제공하는 전국 순환형 트래킹 코스 '코리아둘레길'의 284개 코스 상세 GPX 정보와 주변 관광정보입니다. Open API형태로 2가지 오퍼레이션(코스 목록 정보 조회, 길 목록 정보 조회)을 제공하고 있습니다. 코리아둘레길의 GPX 정보는 두루누비 외 타 어플에도 적용하여 걷기 기록을 측정 할 수 있으며, 트래킹용 스마트 워치에 다운받아 개인별로 기록 측정 및 완주가 가능합니다. 또한 다양한 서비스에 결합하여 새로운 서비스로 재생산 가능한 데이터입니다. 자세한 사용법은 API 명세서를 참고하시기 바랍니다.

## 사용 조건

- 비용: 무료
- 이용허락범위: 이용허락범위 제한 없음
- 심의유형: 개발단계 : 자동승인 / 운영단계 : 심의승인
- 신청 가능 트래픽: 개발계정 : 1,000 / 운영계정 : 활용사례 등록시 신청하면 트래픽 증가 가능
- 인증: 각 기능의 `serviceKey`에 공공데이터포털에서 발급받은 인증키를 전달해야 합니다.

## 호출 방법

Swagger 기준 버전은 `1.0.0`이며 Base URL은 다음과 같습니다.

```
https://apis.data.go.kr/B551011/Durunubi
```

각 기능의 HTTP 메서드와 경로를 Base URL 뒤에 붙여 호출합니다. 응답 형식은 보통 `_type=json`으로 JSON을 지정할 수 있으며, XML도 지원되는 경우가 있습니다. 아래 기능별 표에서 필수 파라미터를 채워 호출하세요.

## 상세 기능

### GET `/courseList` — 코스 목록 정보 조회

코스 목록 정보를 조회하는 기능입니다.

- 호출 주소: `https://apis.data.go.kr/B551011/Durunubi/courseList?MobileOS={MobileOS}&MobileApp={MobileApp}&serviceKey={SERVICE_KEY}`

#### 요청 파라미터

| 이름 | 필수 | 형식 | 위치 | 설명 |
|---|---:|---|---|---|
| `numOfRows` | 아니오 | string | (query) | 한페이지결과수 |
| `pageNo` | 아니오 | string | (query) | 페이지번호 |
| `MobileOS` | 예 | string | (query) | OS 구분 : IOS (아이폰), AND (안드로이드), WIN (윈도우폰), ETC(기타) |
| `MobileApp` | 예 | string | (query) | 서비스명(어플명) |
| `serviceKey` | 예 | string | (query) | 인증키(서비스키) |
| `crsKorNm` | 아니오 | string | (query) | 코스명 |
| `routeIdx` | 아니오 | string | (query) | 길 고유번호 |
| `crsLevel` | 아니오 | string | (query) | 난이도(하:1, 중:2, 상:3) |
| `brdDiv` | 아니오 | string | (query) | 걷기/자전거 구분(DNWW=걷기 길만 제공되고 있음) |

#### 응답

| 코드 | 설명 |
|---:|---|
| 200 | 성공 |

성공 응답 예시(`200`):

```json
{

 },
 "body": {
 "totalCount": 0,

 "crsTourInfo": "string",
 "crsSummary": "string",
 "routeIdx": "string",
 "crsIdx": "string",
 "crsKorNm": "string",
 "crsDstnc": "string",
 "crsTotlRqrmHour": "string",

 }
 },
 "numOfRows": 0,
 "pageNo": 0
 }
}
```
