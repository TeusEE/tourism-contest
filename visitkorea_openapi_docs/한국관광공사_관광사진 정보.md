# 한국관광공사_관광사진 정보

- 출처: [공공데이터포털 상세 페이지](https://www.data.go.kr/data/15101914/openapi.do)
- 수집 기준일: 2026-08-05
- 제공기관: 한국관광공사
- API 유형: REST
- 데이터 포맷: JSON+XML
- 키워드: 포토코리아,한국 관광,사진,사진 공모전,동영상,국내 관광지,문화유산,풍경

## 어떤 정보를 얻을 수 있나

본 API는 한국관광공사에서 제공하는 서비스인 포토코리아(phoko.visitkorea.or.kr)에서 제공하는 사진에 대한 사진 제목, 촬영일, 촬영지, 촬영자, 키워드, 웹용 이미지 URL 등을 제공합니다. 한국의 다채로운 관광사진 10만여 장을 보유하고 있는 포토코리아의 사진들은 공공누리 1유형의 콘텐츠들로서, 자유롭게 다운로드 및 활용이 가능합니다. 모바일 앱 뿐만 아니라, 웹 서비스, 홍보물, 잡지 등 여러 매체에서 활용할 수 있으며 신규/융복합 관광 서비스를 창출할 수 있습니다.

## 사용 조건

- 비용: 무료
- 이용허락범위: 이용허락범위 제한 없음
- 심의유형: 개발단계 : 자동승인 / 운영단계 : 심의승인
- 신청 가능 트래픽: 개발계정 : 1,000 / 운영계정 : 활용사례 등록시 신청하면 트래픽 증가 가능
- 인증: 각 기능의 `serviceKey`에 공공데이터포털에서 발급받은 인증키를 전달해야 합니다.

## 호출 방법

Swagger 기준 버전은 `1.0.0`이며 Base URL은 다음과 같습니다.

```
https://apis.data.go.kr/B551011/PhotoGalleryService1
```

각 기능의 HTTP 메서드와 경로를 Base URL 뒤에 붙여 호출합니다. 응답 형식은 보통 `_type=json`으로 JSON을 지정할 수 있으며, XML도 지원되는 경우가 있습니다. 아래 기능별 표에서 필수 파라미터를 채워 호출하세요.

## 상세 기능

### GET `/galleryList1` — 관광사진갤러리 목록 조회

사진갤러리 목록을 조회하는 기능입니다. 제목으로 중복 콘텐츠를 제거하여 그룹화하고, 사진의 URL경로, 촬영월, 촬영장소 등의 내용을 목록으로 제공합니다.

- 호출 주소: `https://apis.data.go.kr/B551011/PhotoGalleryService1/galleryList1?MobileOS={MobileOS}&MobileApp={MobileApp}&serviceKey={SERVICE_KEY}&_type=json`

#### 요청 파라미터

| 이름 | 필수 | 형식 | 위치 | 설명 |
|---|---:|---|---|---|
| `numOfRows` | 아니오 | number | (query) | 한페이지결과수 |
| `pageNo` | 아니오 | number | (query) | 페이지번호 |
| `MobileOS` | 예 | string | (query) | OS 구분 : IOS (아이폰), AND (안드로이드), WIN (윈도우폰), ETC(기타) |
| `MobileApp` | 예 | string | (query) | 서비스명(어플명) |
| `arrange` | 아니오 | string | (query) | 정렬구분 : A=촬영일, B=제목, C=수정일 |
| `_type` | 아니오 | string | (query) | 응답메세지 형식 : REST방식의 URL호출 시 json값 추가(디폴트 응답메세지 형식은XML) |
| `serviceKey` | 예 | string | (query) | 인증키(서비스키) |

#### 응답

| 코드 | 설명 |
|---:|---|
| 10 | 잘못된요청파라메터에러(INVALID_REQUEST_PARAMETER_ERROR) |
