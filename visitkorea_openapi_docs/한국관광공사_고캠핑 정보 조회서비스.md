# 한국관광공사_고캠핑 정보 조회서비스

- 출처: [공공데이터포털 상세 페이지](https://www.data.go.kr/data/15101933/openapi.do)
- 수집 기준일: 2026-08-05
- 제공기관: 한국관광공사
- API 유형: REST
- 데이터 포맷: JSON+XML
- 키워드: 캠핑,국립공원,휴양,야영장,야영장 정보,휴양지 정보,캠핑장 데이터,여행 데이터

## 어떤 정보를 얻을 수 있나

본 데이터는 한국관광공사에서 제공하는 전국 지방자치단체 인허가 시스템에 등록된 야영장(캠핑장) 운영 현황을 체계적으로 수집한 데이터입니다. 야영장명, 구분 유형, 위치 정보, 화장실·샤워실·개수대 등 편의 시설과 소화기·방화수 등 안전 시설 보유 현황을 포함합니다. 캠핑 관련 정책 수립, 관광 인프라 분석, 안전 관리 체계 구축에 활용 가능하며, 캠핑장 서비스 품질 향상, 지역별 관광 자원 개발 전략 수립, 캠핑 수요 예측 및 시설 투자 계획 수립에 기여할 수 있습니다. 또한 야영장 운영 현황 모니터링, 지역 간 시설 격차 분석, 안전 기준 준수율 평가를 통한 체계적인 관리 방안 도출에도 활용 가능합니다.

## 사용 조건

- 비용: 무료
- 이용허락범위: 이용허락범위 제한 없음
- 심의유형: 개발단계 : 자동승인 / 운영단계 : 심의승인
- 신청 가능 트래픽: 개발계정 : 1,000 / 운영계정 : 활용사례 등록시 신청하면 트래픽 증가 가능
- 인증: 각 기능의 `serviceKey`에 공공데이터포털에서 발급받은 인증키를 전달해야 합니다.

## 호출 방법

Swagger 기준 버전은 `1.0.0`이며 Base URL은 다음과 같습니다.

```
https://apis.data.go.kr/B551011/GoCamping
```

각 기능의 HTTP 메서드와 경로를 Base URL 뒤에 붙여 호출합니다. 응답 형식은 보통 `_type=json`으로 JSON을 지정할 수 있으며, XML도 지원되는 경우가 있습니다. 아래 기능별 표에서 필수 파라미터를 채워 호출하세요.

### GET `/basedSyncList` — 동기화 목록 조회

#### 요청 파라미터

| 이름 | 필수 | 형식 | 위치 | 설명 |

| `pageNo` | 아니오 | number | (query) | 페이지번호 |
| `MobileOS` | 예 | string | (query) | OS 구분 : IOS (아이폰), AND (안드로이드), WIN (윈도우폰), ETC(기타) |
| `MobileApp` | 예 | string | (query) | 서비스명(어플명) |
| `serviceKey` | 예 | string | (query) | 인증키(서비스키) |
| `_type` | 아니오 | string | (query) | 응답메세지 형식 : REST방식의 URL호출 시 json값 추가(디폴트 응답메세지 형식은XML) |
| `syncStatus` | 아니오 | string | (query) | 컨텐츠상태 : (A=신규,U=수정,D=삭제) |
| `syncModTime` | 아니오 | string | (query) | 수정일 : 컨텐츠변경일자 (수정년도,수정년월,수정년월일 입력) |
