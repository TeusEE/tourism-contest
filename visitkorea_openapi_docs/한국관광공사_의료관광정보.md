# 한국관광공사_의료관광정보

- 출처: [공공데이터포털 상세 페이지](https://www.data.go.kr/data/15143913/openapi.do)
- 수집 기준일: 2026-08-05
- 제공기관: 한국관광공사
- API 유형: REST
- 데이터 포맷: JSON+XML
- 키워드: 여행,관광,외국인 의료 방문,치유 여행,K-의료,의료 관광 융복합 클러스터

## 어떤 정보를 얻을 수 있나

한국관광공사가 보유하고 있는 다양한 의료 관광 정보를 실시간으로 제공 받을 수 있으며, 국내 최대 관광정보 포털사이트(www.visitkorea.or.kr) 홈페이지에서 제공하는 의료 관광정보 중 저작권 등에 구애 없이 자유롭게 활용 가능한 정보만을 선별하여 OpenAPI를 통해서 최신 정보를 제공하고 있습니다. - 개방데이터는 법정동 코드 정보, 지역기반 관광정보, 위치기반 관광정보, 키워드 검색, 의료 관광 동기화 정보, 공통정보, 소개정보, 의료 관광정보 8종의 전반적인 국내 의료 관광정보를 여러가지 언어로 제공합니다. - 모바일 앱 뿐만 아니라, 웹 서비스, 태블릿, 홍보물, 잡지 등 다양한 매체에서 어플리케이션을 개발, 활용할 수 있으며, 다양한 활동을 통해서 신규/융복합 관광 서비스를 창출할 수 있습니다.

## 사용 조건

- 비용: 무료
- 이용허락범위: 이용허락범위 제한 없음
- 심의유형: 개발단계 : 자동승인 / 운영단계 : 심의승인
- 신청 가능 트래픽: 개발계정 : 1,000 / 운영계정 : 활용사례 등록시 신청하면 트래픽 증가 가능
- 인증: 각 기능의 `serviceKey`에 공공데이터포털에서 발급받은 인증키를 전달해야 합니다.
