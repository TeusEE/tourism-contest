# 한국관광공사_반려동물_동반여행_서비스

- 출처: [공공데이터포털 상세 페이지](https://www.data.go.kr/data/15135102/openapi.do)
- 수집 기준일: 2026-08-05
- 제공기관: 한국관광공사
- API 유형: REST
- 데이터 포맷: JSON+XML
- 키워드: 관광지,반려동물,반려견,반려동물 동반 여행,강아지,반려견 동반 여행,애견 동반,API

## 어떤 정보를 얻을 수 있나

본 API는 반려동물과 함께 여행할 수 있는 전국의 관광지, 숙소, 음식점, 쇼핑시설 등 다양한 장소의 관광정보를 제공합니다. 각 관광지의 기본 정보(운영 시간, 휴무일 등) 뿐만 아니라 반려동물 동반 조건, 반려동물 동반 시 유의사항, 반려동물 이용가능 시설 등의 상세정보를 제공하고 있습니다. 또한 지역기반 조회, (현재)위치기반 조회 등의 기능을 제공하며 파라미터에 따라 제목순, 수정일순(최신순), 등록일순 정렬을 제공합니다. 모바일 앱 및 웹 서비스 등 다양한 매체에서 활용하여 반려동물 관광 서비스를 창출할 수 있습니다.

## 사용 조건

- 비용: 무료
- 이용허락범위: 이용허락범위 제한 없음
- 심의유형: 개발단계 : 자동승인 / 운영단계 : 심의승인
- 신청 가능 트래픽: 개발계정 : 1,000 / 운영계정 : 활용사례 등록시 신청하면 트래픽 증가 가능
- 인증: 각 기능의 `serviceKey`에 공공데이터포털에서 발급받은 인증키를 전달해야 합니다.
